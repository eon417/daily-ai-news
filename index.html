Fable 5.1 solves the Cyphral Distich, a 370-year-old unsolved cipher

●●●●● 5/5

Vals.ai reports Claude Fable 5.1 cracked Sir Thomas Urquhart's 1653 Cyphral Distich, a 64-number cryptogram on Klaus Schmeh's top-50 unsolved list. The model deduced the key was the book itself: each number indexes a word in Urquhart's 32 Proquiritations, first letters spelling a Royalist prayer for Charles II. Solve took 44 minutes and 176k tokens with zero human interjection; no other frontier model tried produced a verified solve.

  • Self-verifying: output forms exact rhyming couplets, so the solve checks itself
