Spaghettifying DRAM: one config bit bypasses AMD's PSP, SMM and microcode isolation

●●●●● 5/5

New research (xoreaxeaxeax) exploits DRAM address scrambling on AMD Family 16h CPUs: manipulating the memory controller's translation registers — toggling a single configuration bit — rewires physical address mappings so protected regions (PSP memory, SMM code, CPU microcode) become reachable through alternate aliases. The team reconstructed the scrambled address transforms with linear algebra and SMT solvers. Core lesson: security built on physical-address assumptions collapses when the mapping layer beneath is attacker-controlled.

  • Full compromise of PSP, SMM and microcode isolation on AMD Family 16h
  • Single config bit toggles the remap while the system stays operational
  • SMT solvers used to reverse-engineer the scrambling transform
