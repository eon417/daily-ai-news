HybridAgents: LLM agents that reason in latent space and act through text beat frontier agents by 10.4% on 11 benchmarks with 35.5% to 54.7% fewer tokens, 1.8x to 2.6x faster, 2.7x to 3.7x cheaper

●●●●○ 4/5

An arXiv paper (2610.18861, authors including Together AI and Stanford) that reached 218 points on HN proposes HybridAgents, which alternate between latent reasoning and text-based actions in one generation process, using a lightweight link for mode switches and a persistent working memory across turns. Training pairs a supervised stage that teaches tool coordination with an RL stage that learns when to think internally and when to act. Across three model sizes and eleven benchmarks spanning math, science, medicine, search and agentic tasks, it improved on frontier LLM agents and agentic frameworks by 10.4% while cutting tokens 35.5% to 54.7%, speeding inference 1.8x to 2.6x and lowering cost 2.7x to 3.7x. Latent thoughts remain inspectable, addressing the transparency objection to latent reasoning. Code and data are on GitHub.

  • Latent reasoning plus text actions in a single generation loop
  • +10.4% accuracy, up to 54.7% fewer tokens, up to 3.7x cheaper

CarryOn: object-oriented context for long-horizon agents lifts OSWorld 2.0 by 5.8% and BrowseComp-Plus by 7.0% while cutting tokens 51.9% and 22.9%, no training, Claude Opus 4.7 as host

●●●●○ 4/5

The top-voted Hugging Face paper on 10-19 (2610.18784, 24 upvotes) introduces CarryOn, a context runtime that organizes continuation around reusable task objects such as work products and application states rather than the interaction history that produced them. Each context view combines continuation carriers, execution context (goals, constraints, unresolved issues) and a live tail of interactions since the last fold, with carrier records updated across folds. Using Claude Opus 4.7 as host agent, tracker and compiler with no additional training, it improved OSWorld 2.0 by 5.8% and BrowseComp-Plus by 7.0% while reducing total token use by 51.9% and 22.9%. A practical pattern for anyone building compaction into agent harnesses.

You could have invented transformers from memory: linear layers, MLPs and attention as associative memories, with softmax giving ~1M memories at d=64

●●●●○ 4/5

Alex Wang's post, 506 points on Hacker News, derives the transformer stack from one idea: every layer is an associative memory that stores key-value pairs and recalls a value by similarity to a query. Recall quality is the ratio of interference from other memories to the target signal, and capacity is where that ratio hits one. A plain outer-product store holds about as many memories as the key dimension; least-squares fitting roughly doubles it; nonlinear gating such as squared ReLU, which suppresses weakly similar keys, pushes it to about 2,700, which is why MLPs store more than a linear map. Swapping the power for an exponential yields softmax attention, whose capacity grows exponentially with its sharpness, reaching about a million memories at 64 dimensions. Attention is then a non-parametric memory where each context token adds one entry, and scaling the softmax sharpness with context length keeps recall reliable at long contexts.
