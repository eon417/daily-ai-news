JevAgentHarness: hand routine agent decisions to a 4B model, cut agent cost 81 to 89% and run up to 2.5x faster

●●●●○ 4/5

A 10-16 paper on Hugging Face introduces AgentDecisionBench, which evaluates decision models three ways: isolated questions, recorded agent steps, and full tasks. Its key finding is that accuracy on isolated questions does not predict in-agent success, because the states agents actually reach differ from clean benchmark prompts. The accompanying harness lets a small decision model, AgentDecision-4B trained on states real agents reach, take over routine choices such as which tool to call or whether to retry, but only when its confidence clears a threshold fitted on the agent's own runs; everything else falls back to the frontier LLM. On suitable tasks this cuts agent cost by 81.1 to 89.0% and speeds runs up to 2.5x. The approach is the same shape as the routing and confidence-gating patterns now showing up in production agent harnesses.

  • Isolated-question accuracy does not predict in-agent performance
  • Confidence-gated handoff to a 4B decision model
  • 81 to 89% cost reduction, up to 2.5x faster on suitable tasks

PN-Mix: pair-norm guided mixed-precision key-cache quantization hits ~2.26 bits for long-output inference

●●●○○ 3/5

PN-Mix compresses the key half of the KV cache in RoPE-based LLMs by ranking rotary channel pairs by the product of their query and key pair norms and giving higher bit precision to the pairs that matter most. Pairs are chosen once at prefill and reused through decoding, so there is no per-step overhead. At an average of about 2.26 bits it matches or beats prior mixed-precision key-cache methods on long-output tasks, targeting the memory bottleneck that dominates long-generation inference such as reasoning traces and agent transcripts.

  • Exploits RoPE channel-pair structure for precision allocation
  • Decided once at prefill, reused in decoding
  • ~2.26 average bits, competitive with prior methods

●●●●○ 4/5
